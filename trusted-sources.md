# Trusted Sources

The Researcher agent reads this file before every research run. Prefer sources from the
Preferred list. Never use sources from the Blocked list. Flag any research document that
could not find a Tier 1 or Tier 2 source.

---

## Source Priority Hierarchy

When evaluating any source found during research, classify it and note the tier
in the bibliography. Always try to include at least one Tier 1 or Tier 2 source
per research document. Flag in index.md if this was not possible.

| Tier | Type | Examples |
|------|------|---------|
| 1 | Official documentation / authoritative organizations | kafka.apache.org, bjcp.org, sca.coffee |
| 2 | Academic / peer-reviewed / university materials | Google Scholar, PubMed, .edu course pages |
| 3 | Recognized industry institutions | IEEE, ACM, AHA, Specialty Coffee Association |
| 4 | Well-known books (cite even if not web-fetchable) | "How to Brew" by John Palmer, "Designing Data-Intensive Applications" |
| 5 | Established practitioner sites | Long-running expert blogs, named authors with credentials |
| 6 | Community consensus | Reddit, forums, Stack Overflow — only when corroborated by Tier 1-5 |
