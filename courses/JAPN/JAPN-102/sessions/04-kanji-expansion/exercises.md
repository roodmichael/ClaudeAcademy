# Session 04 Exercises

Complete these before taking the session quiz.

## Exercise 1: Radical Decomposition
**Type:** Hands-on

Look up each of the following 10 N3 kanji on Jisho.org. For each one:
1. Identify the radical (Jisho.org shows this in the kanji entry)
2. Name what the radical represents (water, hand, speech, etc.)
3. Write a one-sentence mnemonic story connecting the radical meaning to the kanji meaning

Kanji to analyze: 連、向、様、進、対、最、可、支、感、現

Example:
- 現 (present/appear) → Radical: 王/玉 (king/jewel). Story: "What the king (王) sees (見) is what is real and present."

**What to observe:** Some radicals will connect easily to the meaning; others won't. That is fine — make the story memorable, not logical. Bizarre stories stick better than sensible ones.

## Exercise 2: Jukugo Web — Compound Unlocking
**Type:** Hands-on

Take ONE kanji from this list: 決、政、現、経 (your choice). Go to Jisho.org and look up that kanji. Find 8 compound words (jukugo) that use it.

For each compound:
- Write the kanji
- Write the reading in hiragana
- Write the meaning
- Note whether the kanji appears in the first or second position

Then: Write 2 sentences using compound words from your list.

**What to observe:** Does knowing the single kanji's core meaning help you infer the compound meanings? In some cases (経済 = economy, where 経 = pass through / manage) the connection is logical. In others it is not. Note where the combinatorial logic works and where it doesn't.

## Exercise 4: Thematic Cluster Building
**Type:** Thought experiment

From the thematic clusters introduced in the lesson (Governance, Economic, Change, Emotional, Scientific), choose TWO clusters.

For each chosen cluster:
1. List the kanji from the lesson that belong to it
2. Write 3 jukugo vocabulary words using those kanji
3. Write one sentence using at least two of those vocabulary words

**What to observe:** Does learning kanji in thematic clusters feel different from learning them individually? The goal is to create a network of associations, not a list of isolated symbols.
