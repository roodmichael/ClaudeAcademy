# Session 05 Exercises

Complete these before taking the session quiz.

---

## Exercise 1: Transition Marker Matching
**Type:** Analysis / Written

Match each transition marker to the conversational situation where it fits best. Each marker is used once.

**Markers:** じゃあ / だから / でも / ところで / そういえば / ちなみに / それで

**Situations:**
1. You want to change the topic to weekend plans after a work conversation — cleanly and deliberately.
2. You want to add supplementary information: you mention you've also visited the place being discussed.
3. Someone just explained the problem. You summarize and propose the next step.
4. You want to note the causal connection between two events: because of X, Y happened.
5. A friend is telling a story. You want them to continue: "And then what?"
6. A friend mentioned Tokyo and it reminded you of a friend who lives there.
7. You acknowledge something but want to introduce a contrasting idea.

Write each marker with a sample sentence demonstrating the use.

## Exercise 2: Aizuchi Practice
**Type:** Listening / Speaking

Read the following Japanese monologue slowly out loud (as if you are the speaker). Then read it again, but this time pause at each [PAUSE] marker and say an appropriate aizuchi out loud as if you were the listener.

> 先週ね、久しぶりに友達に会ったんだ。[PAUSE] で、一緒にご飯食べに行ったんだけど、[PAUSE] そのお店がすごく美味しくて。[PAUSE] 値段も安かったし、雰囲気もよくて、[PAUSE] また行きたいってなった。[PAUSE] あ、でも帰りに雨に降られてさ。[PAUSE] 傘持ってなくて、びしょ濡れになっちゃった。[PAUSE]

Write down which aizuchi you used at each pause and why.

**What to observe:** Did you use the same aizuchi twice in a row? Native speakers vary them — へえ, なるほど, そうなんだ, うん, え！ — depending on the content of each sentence. Were you reaching for variety?

## Exercise 3: Filler Recognition
**Type:** Analysis

In each sentence, identify the filler word and its function (hesitation, thinking, softening, attention-getting).

1. あのー、ちょっとよろしいですか。
2. えーと、確か3時ごろだったと思います。
3. うーん、難しいな。もう少し考えさせて。
4. まあ、そういうこともあるよね。
5. なんか、うまく言えないんだけど、すごく良かったって感じ。

## Exercise 4: ちょっと as Refusal — Recognition Drill
**Type:** Analysis / Thought Experiment

For each exchange, decide: is ちょっと functioning as a literal "a little" or as an indirect refusal signal? Write your reasoning.

1. A: 一緒に来ない？B: うーん、ちょっと今日は...
2. A: このスープ、どう？B: ちょっと塩辛いかも。
3. A: これ、もう一度説明してもらえますか。B: ちょっと時間がかかりますが…
4. A: 飲み会来ない？B: その日はちょっと…（間）

**What to observe:** In #4, B trails off without completing the sentence. What does the pause communicate in Japanese culture? Why would B not simply say "No"?

## Exercise 5: Build a Natural Conversation
**Type:** Written Production

Write a 10-line casual Japanese conversation between two friends (call them A and B) that uses:
- At least two different hesitation fillers
- At least two transition markers
- At least three aizuchi from B while A is explaining something
- One indirect refusal using ちょっと

The topic can be anything casual: weekend plans, a recent movie, food, a problem at school or work.

After writing it, read it aloud. Does it sound natural, or does it still feel like textbook Japanese? What would you change?
