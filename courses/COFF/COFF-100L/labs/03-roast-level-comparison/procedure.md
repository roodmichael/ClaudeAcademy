# Lab 03 Procedure: Roast Level Comparison

**Estimated time:** Two roast sessions (~15-20 min each) + 24-48h rest + 45 min comparative cupping
**Beans needed:** 200-240g of your primary (natural-process) bean, green weight (100-120g per roast)

---

## Part A: Two Roast Sessions

Roast A and Roast B can be done in the same session (back to back) or in two separate sessions on the same day. Do not split them across days — you want conditions to be as similar as possible.

### Setting Up for Consistency

Before either roast:
- Decide on your charge weight and use the same for both (100g is a good standard)
- Note your heat and airflow settings — use the same for both roasts
- Note ambient temperature — roasting conditions affect outcomes
- Preheat to the same charge temperature for both

The goal is that the only thing different between Roast A and Roast B is when you stop.

### Roast A: Light Stop (~30 sec after first crack ends)

Follow your standard roast procedure from Lab 02.

**Document in real time:**
- Charge time and weight
- Yellowing time (elapsed)
- First crack onset (elapsed)
- First crack end (elapsed)
- **Drop time: first crack end + 30 seconds**

Store and label immediately: "Lab 03 — Roast A — Light — [date]"

### Roast B: Medium Stop (~2 min after first crack ends)

Repeat the same procedure. All settings identical to Roast A.

**Document in real time:**
- Charge time and weight (should match Roast A)
- Yellowing time (elapsed)
- First crack onset (elapsed)
- First crack end (elapsed)
- **Drop time: first crack end + ~2 minutes**

At 2 minutes past first crack end, you are in medium territory. The bean color will be noticeably darker than Roast A — a deeper, richer brown. You may notice less of the fruity aroma and more of a caramel or chocolate quality in the air.

Store and label: "Lab 03 — Roast B — Medium — [date]"

### After Both Roasts

- Calculate and record weight loss for each roast. Roast B should show higher weight loss.
- Note the color difference between the two batches side by side while they are fresh.
- Rest both for 24-48 hours in separate labeled containers.

## Part B: Writing Your Predictions

Before you cup (during the rest period), write your predictions in your log:

- **3 flavor/aroma words I expect to find in Roast A (light):**
- **3 flavor/aroma words I expect to find in Roast B (medium):**
- **What I think the biggest difference will be:**

This prediction is not graded. It is a thinking exercise that makes the cupping session more informative.

---

## Part C: Side-by-Side Cupping

Cup Roast A and Roast B simultaneously. This is the key word: simultaneously. Comparative cupping only works when both cups are at the same temperature and you can move freely between them.

### Setup

- Grind 8g of each roast to the same coarse grind setting
- Set up two labeled cups: A (Light) and B (Medium)
- Brew both at exactly the same time
- Wait 4 minutes together

### Cupping

1. Break both crusts within 30 seconds of each other. Note each wet aroma.
2. Skim both.
3. Taste A, then B, then A again.
4. Taste B, then A, then B again.
5. Go back and forth freely.

### What to Document

For each roast, fill in the full post-roast evaluation section of your log. Then add a comparative section in your session notes:

| Question | Roast A (Light) | Roast B (Medium) |
|----------|----------------|-----------------|
| Acidity (1-5) | | |
| Sweetness (1-5) | | |
| Body (1-5) | | |
| Finish length | | |
| Primary flavor descriptor | | |
| Secondary flavor descriptor | | |
| Overall (1-10) | | |

**Key comparative questions to answer in your session notes:**

1. Can you taste your natural-process bean's fruit character in both roasts, or does the medium roast begin to bury it?
2. How does acidity change between A and B? Does it shift, or disappear?
3. Where does body land in each cup — and does that match what you predicted?
4. Which do you prefer? Why?
5. Did anything surprise you?
